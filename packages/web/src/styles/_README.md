# styles - Operator Console 视觉系统

> ⚠️ 一旦本文件夹有所变化，请更新本文件

| 文件名 | 地位 | 功能 |
|---|---|---|
| `execution-evidence.css` | 执行证据 | 使用主题变量定义验收表单、审计详情和待处理列表 |
| `theme.css` | 正本 | 集中定义深/浅双主题颜色（`data-theme` 切换）、已知 Actor 语义色、字体、流体讨论列、议题折叠高度、时间线尾部阅读空间、媒体预览尺寸、阴影和层级变量 |
| `app.css` | 布局 | 定义品牌 logo、顶栏项目菜单、中英分段切换、桌面首次设置、三栏骨架、中央讨论列尺寸容器、议题摘要折叠入口、无反弹时间线和错误恢复 |
| `components.css` | 组件 | 定义议题、流体消息/编辑器列、正文折叠、阶梯导航、圆桌三段审查范围、按需运行卡、检查器与决策归档视觉 |
| `orchestration.css` | 运行状态 | 独立定义紧凑历史调用与 Runtime 诊断列表 |
| `runtime-bindings.css` | 持久会话 | 定义每 Agent 最新逻辑绑定状态、session 标记以及关闭/重开操作视觉 |
| `agent-activity.css` | Agent 动态 | 独立定义时间线内 Agent 正在准备/回复卡、在线呼吸点、输入点动画、实时草稿光标和移动端回退 |
| `media.css` | 媒体 | 独立定义图片/Mermaid 有界缩略预览、加载/降级状态和 Portal 全视口缩放浏览 |
| `architecture.css` | 架构档案 | 独立定义项目概览、演进时间线、不变量和架构图集视觉 |
| `mentions.css` | Agent 召唤 | 独立定义自动补全菜单、召唤状态提示和消息流召唤芯片 |
| `model-router.css` | 设置 | 独立定义固定高度 Provider/Agent 路由台、紧凑目录、单项编辑工作台和移动视觉 |
| `manual-decision.css` | 人工决策 | 定义零 Agent 调用提示、人工结束入口与紧凑确认表单的增量视觉 |
| `responsive.css` | 适配 | 定义桌面设置卡、平板/手机讨论列回退、离线入口和低动态偏好规则 |
