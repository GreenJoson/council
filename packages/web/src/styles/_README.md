# styles - Operator Console 视觉系统

> ⚠️ 一旦本文件夹有所变化，请更新本文件

| 文件名 | 地位 | 功能 |
|---|---|---|
| `theme.css` | 正本 | 集中定义全部颜色、Agent、字体、阴影和层级变量 |
| `app.css` | 布局 | 定义顶栏项目菜单、桌面首次设置、三栏骨架和错误恢复 |
| `components.css` | 组件 | 定义议题、消息、完整 Author、编辑器、自动轮次、检查器和对话框视觉 |
| `responsive.css` | 适配 | 定义桌面设置卡、平板、手机离线入口和低动态偏好规则 |
