# src - Council Web 客户端源码

> ⚠️ 一旦本文件夹有所变化，请更新本文件

| 文件名 | 地位 | 功能 |
|---|---|---|
| `main.tsx` | 入口 | 加载字体、主题并挂载 React 应用 |
| `App.tsx` | 核心 | 协调工作区加载、选题、发帖、创建和决策操作 |
| `vite-env.d.ts` | 类型 | 声明 Vite 客户端和环境变量类型 |
| `components/` | 展示 | 保存三栏工作台和交互组件 |
| `data/` | 数据 | 隔离 mock 与后续本地 API 实现 |
| `styles/` | 视觉 | 保存语义主题变量、布局和响应式样式 |
| `types/` | 类型 | 保存 WebUI 领域模型 |
