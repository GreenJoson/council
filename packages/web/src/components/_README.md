# components - Operator Console 界面组件

> ⚠️ 一旦本文件夹有所变化，请更新本文件

| 文件名 | 地位 | 功能 |
|---|---|---|
| `HeaderBar.tsx` | 导航 | 提供项目、搜索、同步状态和全局操作 |
| `TopicSidebar.tsx` | 导航 | 展示项目视图和可筛选议题列表 |
| `DiscussionPanel.tsx` | 核心 | 组织议题头部、讨论时间线和回复编辑器 |
| `MessageCard.tsx` | 核心 | 展示公开 proposal、critique、rebuttal 和 synthesis |
| `Composer.tsx` | 写入 | 发布带类型的公开回复并标明当前数据模式与同步目标 |
| `InspectorPanel.tsx` | 决策 | 展示约束、证据、备选方案和拟议决策 |
| `CreateTopicDialog.tsx` | 创建 | 收集议题问题和约束并提交 repository |
| `presentation.tsx` | 基础 | 统一 Agent 头像和状态标签展示 |
