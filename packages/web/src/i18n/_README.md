# i18n - Council Web 界面语言

> ⚠️ 一旦本文件夹有所变化，请更新本文件

| 文件名 | 地位 | 功能 |
|---|---|---|
| `catalog.en.ts` | 词典 | 以中文固定界面文案为 key，集中保存英文翻译与参数模板；不收录用户正文 |
| `locale.ts` | 偏好 | 优先读取本地手动选择，否则按浏览器/系统语言选择中文或英文，并同步文档语言属性 |
| `I18nProvider.tsx` | 上下文 | 提供全局 locale、持久切换与固定文案翻译；兼容已渲染的参数化系统错误 |

执行交付界面的验收、审计、待处理、提交恢复和未提交代码接续提示均维护中英词条；未知上游文本保留原文，不伪造翻译或状态。
