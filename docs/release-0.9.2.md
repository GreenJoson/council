# Council 0.9.2 发布审核

本版收口决策包、多 Agent 委派、任务验收、执行证据、当前项目待处理与提交检查点恢复，同时包含正式桌面图标和界面调整。图标设计候选素材仅保留本地，不进入仓库或安装包。

## 自审修复

- 执行失败只按原任务版本回写，保留执行期间更新的人工作答与验收证据；任务认领与成功回写继续使用版本 CAS。
- 恢复调用再次失败仍保存原提交检查点；新提交产生后立即保存，后续取消或读取 diff 失败不丢失恢复入口。
- 活动任务委派纳入 Agent/Provider 配置和议题关闭检查；关闭操作在事务内检查，拒绝向已关闭议题、已完成项及父任务发起单项委派。
- 无提交仓库创建初始基线时使用 Git ref CAS，避免覆盖同期产生的首个用户提交。
- 更新 fast-uri、Hono、qs、Mermaid、DOMPurify、nanoid 和 Vitest 等依赖的安全修复版本，并锁定解析结果。

## 边界与替换要求

浏览器验收使用测试 Agent 替身，不代表真实上游模型已经验收。审计仅记录运行时提供的公开事件；没有原生 CLI 工具明细时不补造。Web 构建仍有图表及主入口分块大小提示，不阻断本地应用启动。

安装包应由干净提交执行 `npm run build:desktop` 生成，核对应用内版本、提交标识、签名和二进制哈希后替换。替换前先停止活动运行、退出应用，保留旧应用、设置与 SQLite 一致性备份；启动后核对 schema v16 就绪、数据库身份和历史数据完整性。

旧二进制不保证读取 v16；如需回退到旧 schema，必须配合相应版本的迁移前备份。功能契约与恢复限制见 [执行交付](execution-delivery.md)。
